# FinPay — Fintech API

A secure fintech backend API built for a Parallel and Distributed 
Computing Systems course, focused on secure transaction handling and 
system resilience.

## What it does
- JWT authentication with role-based access control (RBAC)
- AES-256 encryption for sensitive data at rest
- Parallel health checks across system dependencies for resilience 
  monitoring

## Tech stack
ASP.NET Core · SQLite · JWT · AES-256
