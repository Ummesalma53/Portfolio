# Leadgen — Automated Lead Generation Platform

A full-stack platform that automates lead discovery, verification, and 
outreach for local service businesses — built and deployed for Techrive.

## What it does
- Discovers business leads via Adzuna, Google Places, and Hunter.io APIs
- Verifies email deliverability before outreach to protect sender reputation
- Uses the Gemini API for lead qualification and outreach personalization — 
  not just text generation, but decision-making on which leads to prioritize
- Runs staged, scheduled email sequences with a bounce-rate circuit breaker
- Extracts and enriches WhatsApp Business data for multi-channel outreach
- Handles inbound replies via webhook-driven automation
- Dashboard for managing campaigns, templates, and message flows in real time

## Tech stack
**Backend:** Node.js, Express, PostgreSQL, Prisma  
**Frontend:** React  
**AI/Automation:** Gemini API, Hunter.io, Adzuna, ZeroBounce
