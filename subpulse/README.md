# SubPulse — Automated Subscription Tracker

An Android app that automatically discovers and tracks recurring 
subscriptions by scanning a linked Gmail inbox — no manual entry required.

## What it does
- Auto-detects subscription charges and renewals from Gmail
- Surfaces upcoming renewals so users never get surprised by a charge
- Tracks spending across all active subscriptions in one place
- Clean, native Android UI built with Jetpack Compose

## Tech stack
Kotlin · Jetpack Compose · Gmail API integration
